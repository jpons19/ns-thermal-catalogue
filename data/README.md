# Data layers

- `measurements.csv`, `sources.csv`, `references.csv`, `web_table.json`, `web_updates.json`, `raw/`: imported evidence and transcriptions. Do not overwrite a published row to express a review preference.
- `review_decisions.json`: current accepted choices, rejected references and unresolved status. Numeric units are explicit in the field names. B2334 has `display_age_*` rather than an adopted age interval.
- `current_plot_sample.csv`: generated display/export table. Includes upper limits, hotspots and disputed ages. It is not a set of 40 validated independent cooling measurements.

The display table contains literature reference markers for unreviewed sources and explicit review status for Vela/B2334. Vela's retained central marker is the old catalogue location; no new best estimate was selected. The rectangular bounds are an envelope, not a covariance matrix or a distribution. The legacy workbook and Python data module are not regenerated by the current build.

See `docs/DATA_DICTIONARY.md` for the imported table columns and `docs/ns_thermal_literature_audit.md` for interpretation.
